# Changelog

All notable changes to DevLoop Agents are documented here.

## 0.1.0 — 2026-09-24

- Introduced portable coder, QA, and monitor orchestration.
- Added GitHub Issues and offline local tracker adapters.
- Added provider-neutral command execution, structured results, leases, budget guards, and JSONL events.
- Added HTTP and command health probes with incident deduplication.
- Added a responsive local operations dashboard.
- Added Docker Compose, CI, public documentation, examples, and security controls.
